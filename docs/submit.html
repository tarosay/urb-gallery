作品を出す

ギャラリーに並べたい作品の出しかたです。出すのは、大人の方にお願いしています。

作った人の名前は、ニックネームにしてください。 ここに書いたことは誰でも見られる場所に出ます。本名・学校名・住所は書かないでください。

まず、作品のファイルを作る

子が URB Block Lab で 「.rb で保存」を押すと、作品のファイルができます。これを受け取ってください。

この .rb は、そのまま動く Ruby の後ろに、ブロックの並びが # urb-block/1 … というコメントで畳んで入っています。 ギャラリーはそこを読んでブロックに戻すので、このコメントを消すと開けなくなります。 メモ帳などで開いて消さないでください。

出しかた（GitHub のプルリクエスト）

作品 1 件は新しいファイル 2 つです。すでにあるファイルには触りません。 そうしてあるので、何人が同時に出しても、ぶつかりません。

  1. 名前（id）を決める

    半角英数と - _ . だけで、短くつけます（例: blink-taro）。 ファイル名と、ページのアドレスに使われます。すでにある作品と同じ名前にはできません。

  2. 2 つのファイルを置く
    • docs/works/<id>.rb — 受け取った .rb の名前を変えたもの
    • docs/works/<id>.json — 下の書きかたで作る

    絵を付けたいときは docs/thumbs/<id>.png も置きます（無くてかまいません）。

  3. プルリクエストを出す

    urb-gallery に対して出してください。 GitHub のページ上だけでもできます（次の節）。

  4. 点検が通るのを見る

    プルリクエストを出すと、書きかたの点検が自動で走ります。緑になれば大丈夫です。 赤くなったら、何が悪いかがそこに出ます。

GitHub のページ上だけで出す

Git のコマンドは要りません。ブラウザだけで最後まで進められます。

  1. urb-gallery を開いて、右上の Fork を押す（自分のコピーができます）
  2. コピーのほうで docs/works フォルダを開き、Add file → Upload files で <id>.rb を置く
  3. 同じ所で Add file → Create new file を選び、名前を <id>.json にして、下のひな形を貼って書き換える
  4. 画面の下で Commit changes（新しいブランチを作る方を選んでおくと安全です）
  5. Contribute → Open pull request を押す

<id>.json の書きかた

{
  "title": "1秒ごとに光る",
  "author": "たろう",
  "group": "○○クラブ",
  "region": "和歌山県",
  "kind": "光る",
  "desc": "ピン2につないだ LED を、1秒ごとに点けたり消したりします。",
  "tags": ["LED", "はじめて"],
  "lab": "block",
  "date": "2026-09-03"
}
項目中身
（ファイル名）id は書きません。<id>.json の <id> がそのまま使われます
title題名
author作った人。ニックネームで
group所属（教室・クラブ・学校など）。無ければ省略できます
region都道府県。「県」「府」「都」まで書きます（「和歌山」だけでは点検で止まります）
kind種類。下の 7 つから 1 つ
descひとこと説明
tags自由に何個でも。# は付けません（出すときに付きます）
labblock（URB Block Lab で作ったもの）
date作った日。2026-09-03 の形で

種類

光る 音 うごく はかる ゲーム・あそび 役に立つもの その他

点検で止まったら

よくあるのは次のものです。書き直して、もう一度置けば通ります。

出るもの直しかた
<id>.rb がありません.json と .rb の名前を同じにします
kind「…」は種類の一覧にありません上の 7 つのどれかにします
region「…」は都道府県ではありません「和歌山県」のように最後まで書きます
tags に # は付けません["LED"] のように書きます
.rb に「# urb-block/1 …」の行がありませんURB Block Lab の「.rb で保存」で出したファイルを置きます

入ったあと

プルリクエストが取り込まれると、一覧は自動で作り直されます。 目次のファイルを誰かが書き足す必要はありません。しばらくすると 作品の一覧に並びます。

くわしい仕組みは urb-gallery の README にあります。
